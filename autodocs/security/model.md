# Security Model

### Security Model
The package generates emails locally using fixed name and domain lists. There are no known security concerns related to data handling.

### Reporting Vulnerabilities
Please report security issues through the GitHub issues page: [https://github.com/automationpi/email-generator/issues](https://github.com/automationpi/email-generator/issues)

### Responsible Disclosure Policy
Follow standard responsible disclosure practices via the project's GitHub repository.
