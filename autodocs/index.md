# Email Generator**What It Does**  
Email Generator is a lightweight Node.js package designed to create unlimited, random, and unique email addresses. It is primarily intended for use in automated testing scenarios where distinct email inputs are required to simulate user registration, login, or other email-dependent workflows.

**Key Features**  
- Generates realistic email addresses combining random first names, last names, and domains.
- Produces unique email addresses with appended random numbers.
- Simple API with a single function: `generateEmail()`.
- Suitable for automated testing environments.

**Project Status / Roadmap**  
The project is in a stable state with core functionality implemented. Future enhancements could include more customizable email patterns, additional domain options, or integration with mock email services.
